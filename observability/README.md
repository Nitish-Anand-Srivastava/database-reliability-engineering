# Observability

This area contains **monitoring and diagnostic outputs** that are not limited to a single engine package.

## Major subareas

- `platform-monitoring/` — top-level monitoring assets moved from the previous layout
- `database/` — database observability references
- `legacy-monitoring/` — monitoring assets preserved from earlier repository structure

## Guidance

Put dashboards, alerts, and monitoring rule sets here when they are shared across multiple platforms or represent estate-level observability practice. Historical multi-engine reporting bundles that are no longer part of the active opinionated toolkit belong in `archive/`.

# AWS Databases

This area contains **AWS-managed database operational material** with a bias toward **hands-on troubleshooting and performance triage** rather than generic cloud notes.

## Active focus

- `rds/postgresql/` — primary AWS RDS PostgreSQL troubleshooting and performance pack
- `rds/monitoring/` — engine-agnostic RDS review guidance

## Legacy reference

- `cloud/` — older cloud/provider notes preserved for reference
- `rds/mysql/`, `rds/oracle/`, `rds/sqlserver/` — lighter engine-specific material retained until refreshed

## Guidance

If you are adding **new AWS performance troubleshooting content**, prefer:

1. `rds/postgresql/` for PostgreSQL operational SQL and helper procedures
2. `rds/monitoring/` for shared RDS review guidance
3. `cloud/` only for provider-level reference that is not an active DBRE workflow

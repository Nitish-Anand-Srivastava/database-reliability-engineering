# Archive

This area preserves **legacy, lower-priority, or non-core material** that the team may still want as reference.

## Why it exists

The repository used to mix active DBRE content with broad data-engineering and multi-engine legacy material. Rather than delete potentially useful material, it is intentionally retained here.

Examples now archived here include:

- legacy `database_admin/` material that no longer drives the active structure
- older data-engineering and generic SQL areas
- historical multi-engine performance report generators

## Guidance

- Do **not** put new primary content here.
- Promote archived material back into the active top-level structure only when it is refreshed and intentionally adopted.
